SENTINEL 공통 이벤트 스키마 1차 수정

추가 필드
- timestamp: 외부 데이터 원본 발생 시각 보존 (기존 필드 활용)
- host: 이벤트 발생 PC/호스트
- source: windows_event_log / usb_collector / simulator / public_dataset 등 수집원
- raw_event_id: 원본 이벤트 종류/ID
- file_path: 파일 전체 경로
- device_name: 장치 이름
- device_id: 장치 식별자

수정 파일
- server/models.py
- server/main.py
- server/schema_migration.py (신규)
- client/windows_collector.py
- client/usb_collector.py
- client/simulator.py

호환성
- 기존 /events 요청 형식 그대로 사용 가능
- 기존 security.db 삭제 불필요
- 서버 시작 시 기존 security_events 테이블에 없는 새 컬럼만 자동 추가
- 기존 이벤트 데이터 유지

검증
- Python compileall 통과
- 기존 DB 1,549건 유지 확인
- 공통 필드 ORM insert/rollback 테스트 통과
